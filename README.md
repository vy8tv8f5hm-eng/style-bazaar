# StyleBazaar - ستايل بازار
## تطبيق التسوق الأنيق للموضة السعودية

### 🎯 الفكرة الأساسية
تطبيق تسوق متخصص في الموضة السعودية يجمع بين الأناقة والتكنولوجيا، مع تجربة تسوق سلسة وسهلة للعملاء السعوديين والخليجيين.

### ✨ المميزات الرئيسية

#### 1. **التطبيق الويب التقدمي (PWA)**
- يعمل بدون اتصال بالإنترنت
- قابل للتثبيت على الهاتف مباشرة
- تجربة سريعة وسلسة

#### 2. **واجهة عربية بالكامل (RTL)**
- تصميم مخصص للغة العربية
- تجربة محسّنة للمستخدم العربي
- ألوان وتصاميم تعكس الجمالية السعودية

#### 3. **نظام إدارة المخزون الذكي**
- عرض المنتجات حسب الحجم واللون
- معلومات مباشرة عن التوفر
- تتبع المبيعات والمخزون

#### 4. **سلة التسوق المتقدمة**
- إضافة وإزالة المنتجات بسهولة
- تحديث الكميات
- عرض السعر الإجمالي

#### 5. **نظام المفضلة**
- حفظ المنتجات المفضلة
- نشاركة القوائم مع الأصدقاء
- توصيات مخصصة

#### 6. **البحث والتصفية المتقدمة**
- البحث السريع في المنتجات
- تصفية حسب:
  - الفئة (ملابس، أحذية، إكسسوارات)
  - السعر
  - الحجم
  - اللون
  - التوفر

### 🏗️ البنية التقنية

#### Frontend Stack
- **React 18** - مكتبة واجهات المستخدم
- **Vite** - أداة بناء سريعة
- **Tailwind CSS** - إطار عمل للتنسيق
- **Zustand** - إدارة الحالة

#### Backend & Database
- **Supabase** - قاعدة بيانات PostgreSQL سحابية
- **Authentication** - تسجيل الدخول الآمن
- **Real-time Updates** - تحديثات فورية

#### الميزات التقنية
- **Responsive Design** - يعمل على جميع الأجهزة
- **PWA Support** - تطبيق ويب تقدمي
- **Offline Mode** - يعمل بدون إنترنت
- **Fast Performance** - أداء عالي جداً
